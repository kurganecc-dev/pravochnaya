# Правочная — видеоправки + Adobe Premiere Pro

Единый статический сервис для просмотра видео, создания правок по таймкодам и передачи их монтажёру.

Теперь экспорт в Adobe Premiere Pro встроен прямо в основную «Правочную»: отдельный сайт-конвертер и промежуточный импорт JSON не нужны.

## Возможности

- локальное видео из браузера;
- прямые ссылки на видео;
- публичные ссылки Яндекс Диска через Cloudflare Worker;
- комментарии на точных таймкодах;
- рисунки поверх кадра;
- скриншоты, статусы, фильтры и маркеры на таймлайне;
- автосохранение и импорт/экспорт JSON;
- CSV, TXT, HTML и обычный ZIP-отчёт;
- встроенный экспорт **Adobe Premiere Pro**:
  - Final Cut Pro 7 XML (`xmeml v5`);
  - sequence markers с полным текстом правок;
  - прозрачные PNG-оверлеи;
  - автоматическое разнесение пересекающихся карточек по видеодорожкам;
  - CSV/JSON-манифест и инструкция монтажёру.

Все кадры и PNG создаются локально в браузере.

## Как пользоваться экспортом Premiere

1. Откройте видео в «Правочной».
2. Добавьте комментарии и, при необходимости, нарисуйте пометки.
3. Нажмите **Экспорт → Premiere Pro**.
4. Укажите FPS, разрешение и стартовый таймкод монтажной секвенции.
5. Скачайте ZIP и полностью распакуйте его.
6. В Premiere Pro выберите **Файл → Импорт** и откройте `pravochnaya-premiere.xml`.
7. Если PNG отображаются Offline, выберите **Link Media / Связать медиа** и укажите первый файл из папки `overlays`.
8. Перетащите импортированную секвенцию на верхнюю видеодорожку основного монтажа от самого начала.

FPS, разрешение и стартовый таймкод должны совпадать с монтажной секвенцией.

## GitHub Pages

1. Загрузите содержимое репозитория в GitHub.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **GitHub Actions**.
4. Сделайте push в ветку `main`.

Workflow `.github/workflows/pages.yml` запустит тесты и опубликует папку `docs`.

## Локальный запуск

```bash
python3 -m http.server 8080 --directory docs
```

Откройте `http://localhost:8080`.

## Яндекс Диск

Адрес Worker задаётся в `docs/config.js`:

```js
window.VIDEO_REVIEW_CONFIG = {
  apiBaseUrl: 'https://video-review-yandex-api.kurganecc.workers.dev',
};
```

Исходники Worker находятся в `worker/`.

Для повторного развёртывания:

```bash
cd worker
npm install
npx wrangler login
npm run deploy
```

Перед рабочим использованием замените `ALLOWED_ORIGINS: "*"` в `worker/wrangler.jsonc` на адрес GitHub Pages или корпоративный домен.

## Структура

```text
docs/
  index.html              единый интерфейс Правочной
  styles.css              стили
  app.js                  видеоплеер, правки и все экспорты
  config.js               адрес Cloudflare Worker
  lib/premiere.js         таймкоды, маркеры и Final Cut Pro 7 XML
  lib/overlay.js          прозрачные PNG-оверлеи

worker/                   прокси Яндекс Диска с Range/CORS
.github/workflows/        тестирование и GitHub Pages
tests/                    unit и integration smoke-тесты
```

## Ограничения

- XML создаёт отдельную секвенцию и не изменяет автоматически уже открытую секвенцию монтажёра.
- Для 29.97 и 59.94 используется NDF-таймкод; drop-frame пока не реализован.
- Прямые ссылки на видео должны разрешать CORS, иначе браузер не сможет снять кадр.
- Большое количество скриншотов может заполнить `localStorage`; регулярно сохраняйте JSON или ZIP.
